# 硬件 · Arduino Uno + MAX30102 + Grove GSR

从完整教程中提炼的重点：选品、接线、固件、调试。
完整固件：[`sensor_hrv_v8/sensor_hrv_v8.ino`](sensor_hrv_v8/sensor_hrv_v8.ino)。

## 测量什么

- MAX30102 PPG 模块：心率（BPM）与心率变异性（HRV/RMSSD）
- Grove GSR 模块：皮肤电（GSR）
- 原理一句话：紧张时交感神经兴奋 → 心跳变快变整齐、手心出汗；放松时副交感
  神经主导 → 心跳慢但波动大。两个信号交叉验证。

## 选品

| 物料 | 参考价 | 选购要点 |
|---|---|---|
| **Arduino Uno R3** | 25~150 元 | 国产兼容板即可；认准数据线是**数据线**不是纯充电线 |
| **MAX30102 心率血氧模块** | 8~20 元 | 买 **3.3V~5V 兼容**版（丝印 `VIN`）。别买成 MAX30100（算法不兼容）或 MAX7219（那是数码管驱动！） |
| **Grove GSR 皮肤电传感器** | 40~60 元 | Seeed 原版或兼容版，必须带**两个指套电极**。模拟输出，无需库 |

辅料：400 孔面包板、公对母杜邦线 10 根以上（红=电源、黑=地、其他=信号）、
橡皮筋或魔术贴固定手指（比手按稳定十倍）。可选：Grove Base Shield、
万用表（蜂鸣档查短路是调试神器）。

## 接线

本项目用到两类接口：

| 接口 | 用在哪 | 特点 |
|---|---|---|
| **I2C**（A4=SDA, A5=SCL） | MAX30102 | 固定地址 `0x57` |
| **模拟输入**（A0） | GSR | `analogRead` 读 0~1023 |

**MAX30102（8 焊盘只用 4 个）：**

| 丝印 | 接法 |
|---|---|
| VIN | Uno 5V |
| GND（两个任选一） | Uno GND |
| SDA | Uno A4 |
| SCL | Uno A5 |
| INT / RD / IRD | 不接 |

**Grove GSR（3 根线）：** 红（VCC）→ 5V；黑（GND）→ GND；黄/白（SIG）→ A0。

**上电前检查：**

1. 断电接线，接完逐根对照表格。
2. 万用表蜂鸣档测 (+) 排和 (-) 排：不响 = 没短路 = 可以上电。
3. SDA/SCL 接反不会烧板，只是没数据；**VCC/GND 接反可能烧模块**。
4. 上电验收：手指盖住传感器能看到**暗红色光**。

## 固件

Arduino IDE + **`DevLab MAX30102`** 库（SparkFun `MAX3010x` 也行，API 几乎一样）。
开发板选 Arduino Uno。**串口波特率必须是 115200**——不一致就是满屏乱码，
新手第一大坑。

`sensor_hrv_v8.ino` 要点：

- IR 通道做心跳检测；IR > 50000 判定有手指
- BPM 取最近 2 次心跳均值；RMSSD 取最近 12 个 RR 间隔（至少 5 个才输出）
- I2C 看门狗：每 2 秒探测 0x57 地址应答，无应答才重建总线
  （100kHz 总线速度防静电锁死）
- 拿开手指所有数值立即归零
- 输出已适配本项目串口契约——每秒一行 JSON：
  `{"hr":72,"gsr":512,"rmssd":42.3}`（数据不足时省略 `rmssd` 字段，
  后端沿用上一帧值）

**佩戴**：MAX30102 用食指指腹轻盖传感器窗口，橡皮筋固定；GSR 两个指套戴
**同一只手**的食指+中指；两只传感器分开放两只手。

**自验证场景**：缓慢深呼吸（吸4s呼6s）1 分钟 → RMSSD 爬升；憋气 15 秒或
连续心算减 7 → BPM、GSR 上升；拿开手指 → 1 秒内 BPM 归零。

## 调试经验（踩过的所有坑）

| 症状 | 根因 | 解法 |
|---|---|---|
| 串口满屏乱码 | 波特率不一致 | 监视器改 115200 |
| `MAX30102 not found` | SDA/SCL 接反或松动 | 断电重插核对 |
| 手一碰传感器程序就死 | I2C 400kHz + 飞线 + 静电锁死总线 | 降速 100kHz；手指只碰窗口不碰焊盘；加看门狗 |
| BPM 卡一个值不动 | 算法只在抓到心跳时更新 + 按压不稳 | 调按压；等 10 秒冷启动 |
| 拿开手指数值不回去 | 代码没处理"没手指" | 加 `!fingerOn` 归零逻辑 |
| 放回去永远是 0 | 看门狗把"无新样本"误判为总线锁死，反复重启传感器 | 看门狗改用 I2C 地址应答探测 |
| 烧录后串口空白 | IDE2 串口监视器假死/被绘图器占用 | 关干净监视器重开，按 RESET |

**通用纪律**：能跑的代码先备份再改；一次只改一处；报错原文一字不差记录。

## 能力边界

GSR 指示"唤醒度"很强，HRV 指示"放松↔紧张"较强，但**单靠这两个信号估
欢愉度（效价）本质上是粗略的**（学界准确率约 40~50%）。本项目输出适合
做趋势参考和演示，不适合做医学/心理结论。
